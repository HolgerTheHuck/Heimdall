# Sicherheitsrichtlinie

## Gemeldete Schwachstellen

Heimdall ist derzeit ein **privates Repository**. Bis zur 1.0-Veröffentlichung
werden Sicherheitsmeldungen bitte **nicht** über öffentliche GitHub-Issues
erstellt, sondern vertraulich über:

- **GitHub Private Security Advisories** (Reiter „Security" →
  „Report a vulnerability"), oder
- E-Mail an **h.huckfeldt@googlemail.com**.

Bitte meldet keine Sicherheitslücken in öffentlichen Issues, damit wir eine
verantwortungsvolle Behebung koordinieren können.

## Reaktionszeit

Wir bemühen uns, Sicherheitsmeldungen innerhalb von **5 Werktagen** zu
bestätigen und so schnell wie möglich eine Behebung oder Mitigation zu
liefern.
